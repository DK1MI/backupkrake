Repository
SFTP repositories (Hetzner Storage Box, NAS, any SSH server)

For sftp: repositories Backupkrake logs in with its own offsite key. Add this public key to the authorized_keys of the account on the SFTP server:

{{ offsite_pubkey }}

The server's host key is learned on first contact and kept in /config/ssh/known_hosts. For a non-standard port, use the URL form sftp://user@host:PORT//absolute/path (a single / after the port means a path relative to the login directory).

Hetzner Storage Box: enable SSH support, then install the key from any machine with echo '{{ offsite_pubkey }}' | ssh -p 23 uXXXXX@uXXXXX.your-storagebox.de install-ssh-key and use sftp://uXXXXX@uXXXXX.your-storagebox.de:23//backupkrake.
