Connection
Client setup: add this line to /root/.ssh/authorized_keys 
{{ keys.system.backup }}

This restricts the key to read-only rsync. See Setup for details and the unrestricted variant (needed for pre/post commands).

Client setup: add this line to ~/.ssh/authorized_keys of that user 
{{ keys.home.backup }}

The key can then only read files inside that user's home folder (. is the home folder, because ssh starts forced commands there). No root access is needed on the host.

No rrsync on that system? It's a small Python script: copy it to e.g. ~/bin/rrsync and use the full path in command="…". Without Python, use the plain key (Setup); it then has the same rights as the account.

For restores to this host, also add: {{ keys.home.restore }}
